# Alytic — محلل البورصة المصرية

محرّك تحليل فني وأساسي لأسهم البورصة المصرية، مع طبقة محلل ذكي بتدي توصيات شراء وبيع،
وقف خسارة، وأهداف على المدى المتوسط والبعيد — بالعامية المصرية.

---

## المبدأ الأساسي: الحساب في الكود، الحكم في النموذج

كل رقم في النظام ده **محسوب حسابيًا**، مش متسأل عنه لنموذج لغوي:

- المؤشرات (RSI, MACD, ATR, ADX, بولينجر) — `src/ta/indicators.js`
- الدعوم والمقاومات — `src/ta/levels.js`
- الوقف وحجم المركز — `src/scoring/risk.js`
- الأهداف والتقدير الزمني — `src/scoring/targets.js`
- التقييم من 100 — `src/scoring/technical.js`

النموذج بياخد الأرقام دي **جاهزة** وشغله إنه:
1. يحل التناقضات (اتجاه صاعد بس ADX ضعيف؟ RSI عالي مع حجم ضعيف؟)
2. يحط الرقم في سياقه
3. يكتب القرار والأمر بالعامية

**النتيجة:** نفس الأسعار بتدي نفس الأرقام دايمًا. النموذج ما بيخترعش سعر ولا وقف ولا هدف.
وكمان — **التحليل الفني كله شغال من غير مفتاح API**. النموذج إضافة، مش شرط.

## التشغيل

```bash
npm install
cp .env.example .env      # وحط مفتاح Anthropic لو عايز التوصيات الذكية
npm run serve             # http://localhost:3000
```

### من سطر الأوامر

```bash
node src/cli.js scan                    # مسح السوق كله مرتب بالتقييم
node src/cli.js scan --actionable       # الفرص القابلة للتنفيذ النهاردة بس
node src/cli.js analyze COMI            # تحليل كامل لسهم
node src/cli.js buy SWDY 300 95.00      # تسجيل شراء
node src/cli.js sell SWDY 100 136.20    # تسجيل بيع
node src/cli.js cash 250000             # تحديث الكاش
node src/cli.js review                  # مراجعة المحفظة بالذكاء الاصطناعي  (محتاج مفتاح)
node src/cli.js fundamentals ABUK       # بيانات الشركة الأساسية من الإنترنت (محتاج مفتاح)
```

## مصدر البيانات

أسعار الإغلاق اليومية بتيجي من Yahoo Finance تحت لاحقة `.CA` (القاهرة) — OHLCV كامل،
عمق يوصل 5 سنين، لـ 43 سهم من أصل 47 في القائمة.

نقطتين مهمين اتأكدنا منهم على البيانات الحية:

1. **`meta.regularMarketPrice` مش موثوق لأسهم البورصة المصرية.** ياهو بيدمج السهم مع صناديق
   ليها نفس الاسم — COMI بيرجّع `81.2` و`instrumentType: MUTUALFUND` في نفس الرد اللي فيه
   إغلاق حقيقي `142.00`. الكود بيقرا من السلسلة الزمنية بس.
2. **آخر شمعة بترجع أحيانًا فاضية** (الجلسة لسه شغالة). بتتشال، ما بتتعبّاش بآخر سعر.

### بوابة جودة البيانات

`src/data/quality.js` بترفض أي سهم بياناته مش سليمة قبل ما توصل لأي مؤشر. ده اتبنى بعد ما
ياهو رجّع **ORAS بـ 489 شمعة متطابقة عند 71.05** (السهم موقوف والخدمة بتكرّر آخر سعر) —
والمحرك وقتها حسبله تقييم 44/100 ووقف وحجم مركز لسهم ما اتداولش أصلًا.

بترفض: بيانات مجمدة، أسهم متأخرة أكتر من 5 جلسات، تاريخ أقصر من 60 جلسة، وأسعار غير منطقية.

**البيانات الأساسية مش موجودة على ياهو للبورصة المصرية** (`No fundamentals data found` لكل
الأكواد)، عشان كده بيتجمّعوا من الإنترنت بأداة البحث وبيتخزّنوا 45 يوم.

## قواعد التداول

كل القواعد في `src/config/rules.js` — غيّر رقم هناك وهيتغيّر في المحرك وفي تعليمات المحلل مع بعض.

| القاعدة | القيمة |
|---|---|
| الوقف | 2.5× ATR أو تحت الدعم، بحد أقصى 12% مخاطرة |
| الوقف المتحرك | 8% تحت القمة، بيتفعّل عند ربح 12%، بيطلع بس |
| بيع جزئي | 30% عند ربح 15% بأمر محدد فوق السعر 2% |
| المخاطرة للصفقة | 1.5% من رأس المال |
| الحد الأقصى للمركز | 15% · وللقطاع 30% |
| أقل عائد/مخاطرة مقبول | 1.8 |

### إزاي بتتحسب الأهداف

- **الهدف المتوسط** (أسابيع لشهور): أقرب مقاومة حقيقية → أو الحركة المقاسة بعد اختراق →
  أو قمة 52 أسبوع → أو إسقاط تقلب. بسقف 35% فوق السعر، عشان مستوى على بعد 80% ده هدف بعيد مش متوسط.
- **الهدف البعيد** (6-18 شهر): امتداد فيبوناتشي 1.618 أو استمرار نص وتيرة آخر 6 شهور — أيهما أقل.
  ولو السهم في اتجاه هابط، **مفيش هدف بعيد** لحد ما الاتجاه ينقلب.
- **التوقيت**: من نسبة كفاءة كوفمان (Efficiency Ratio) — قد إيه من مدى اليوم بيتحوّل لتقدم فعلي
  في اتجاه واحد. سهم بيتذبذب بياخد وقت أطول من سهم بيمشي في خط. وفيه سقف على التقدم اليومي
  (1% من السعر) عشان ما نمدّش موجة سريعة لشهور.

## البنية

```
src/
  config/universe.js     43 سهم بأسمائهم وقطاعاتهم

  data/yahoo.js          جلب الأسعار
  data/cache.js          كاش يومي (البورصة بتقفل مرة واحدة في اليوم)
  data/quality.js        بوابة رفض البيانات الفاسدة
  ta/indicators.js       المؤشرات الفنية
  ta/levels.js           الدعوم والمقاومات
  ta/snapshot.js         اللقطة الفنية الكاملة
  scoring/               الوقف، الأهداف، التقييم
  agent/                 طبقة المحلل الذكي
  analyze.js             تجميع كل ده في تحليل واحد
  api/server.js          REST API
public/index.html        الواجهة
```

## ملاحظات

- `egx-desk.html` هو الملف القديم. بيستدعي `api.anthropic.com` من المتصفح من غير مفتاح ومن
  غير `anthropic-version` header — يعني ما كانش بيشتغل أصلًا (CORS)، ولو كان اشتغل كان
  هيسرّب المفتاح لكل زائر. كل استدعاءات النموذج دلوقتي بتحصل في الخادم.
- الملف ده متبني (minified) من غير سورس، عشان كده الواجهة الجديدة اتكتبت من الأول في
  `public/index.html` — HTML و CSS و JS مقروءين، من غير خطوة build.

### التوافق مع الشريعة

حقل `shariah` في `universe.js` **استرشادي بس** — بيعكس نشاط الشركة الظاهر (بنوك تقليدية،
تأمين تقليدي)، مش النسب المالية اللي محتاجة ميزانية كل ربع سنة. `review` معناها راجعها بنفسك.
